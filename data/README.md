# Demo Data Generation (`data/`)

This directory will contain synthetic dataset generators, raw CSV/JSON dumps, and processed seed data files for the demo company (NovaMart Retail Solutions).

## Directory Structure

```
data/
├── generators/ # Python scripts to generate synthetic transactions, stores, and products
├── raw/        # Unprocessed generated CSV/JSON data files
├── processed/  # Cleaned, relational-checked seed datasets
└── README.md   # Documentation
```

## Planned Demo Target (Phase 3)
* 10 Stores
* 5 Warehouses
* 50 Products
* 200 Employees
* 20,000+ Customers
* 100,000+ Sales Transactions (spanning 3 years)
